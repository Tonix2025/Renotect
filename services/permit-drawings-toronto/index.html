BCIN

What is a BCIN Qualified Designer?

A BCIN is a Building Code Identification Number issued in Ontario. Designers who hold one have passed the provincial exams for the categories they practise in, and can prepare and submit drawings for a building permit in those categories.

For houses and many small buildings, the Ontario Building Code allows the drawings to be prepared by a BCIN Qualified Designer. Larger or more complex buildings require an architect.

FAQ

Permit questions

Do I need a permit for my renovation?

Many projects do, especially those that change the structure, add space, move or add plumbing, or change how a space is used. Cosmetic work usually does not. We tell you early which approvals your project needs.

Do I need an architect or can a BCIN designer do my drawings?

For houses and many small buildings, the Ontario Building Code allows the drawings to be prepared by a BCIN Qualified Designer. Larger or more complex buildings require an architect.

How long does a building permit take in Toronto?

Review times depend on the municipality, the type of project and how complete the application is. A complete, clear drawing set helps avoid delays during the review.
